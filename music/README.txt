Thư mục chứa nhạc nền (BGM) cho buổi live.
- Bạn có thể chép trực tiếp các file nhạc (.mp3, .wav, .flac, .m4a, .ogg, .aac, .opus) kể cả file dài > 500MB - nhiều GB vào thư mục này, sau đó bấm "Quét lại" trên Bảng điều khiển (mục 07).
- Hoặc bấm nút "+ Chọn file nhạc (>500MB)" ngay trong Bảng điều khiển để tải vào đây.
- Server phát nhạc bằng kỹ thuật HTTP Range Streaming nên không tốn RAM dù file nặng hàng GB.
